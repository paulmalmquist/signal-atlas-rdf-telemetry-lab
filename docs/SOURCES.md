# Primary references

Checked September 16, 2026. The application deliberately targets RDF 1.1 and SPARQL 1.1 constructs; this is not a claim that these are the newest editions of every specification.

1. W3C, **RDF 1.1 Concepts and Abstract Syntax**. Triples, IRIs/literals, datasets, named graphs and explicit treatment of time: https://www.w3.org/TR/rdf11-concepts/
2. W3C, **SPARQL 1.1 Query Language**. SELECT, ASK, CONSTRUCT, graph patterns, FILTER, property paths and GRAPH: https://www.w3.org/TR/sparql11-query/
3. W3C / OGC, **Semantic Sensor Network Ontology**. The SOSA vocabulary for sensors, observations, observed properties and features of interest: https://www.w3.org/TR/vocab-ssn/
4. W3C, **PROV-O: The PROV Ontology**. Entity, derivation and generation terms: https://www.w3.org/TR/prov-o/
5. W3C, **Shapes Constraint Language (SHACL)**. Shape-based graph validation: https://www.w3.org/TR/shacl/
6. RDFLib, **Security considerations**. Network/file access risks and execution boundaries: https://rdflib.readthedocs.io/en/latest/security_considerations/
7. GitHub CLI, **gh repo create**. Private repository publication: https://cli.github.com/manual/gh_repo_create
8. QUDT, **Units vocabulary**. The namespace reused for unit identifiers: https://qudt.org/vocab/unit/

All fixtures, training scenarios, application views, expected answers and design recommendations are original to this synthetic lab. Reusing vocabulary names does not imply complete conformance, endorsement or an approved company ontology. The bounded local SHACL evaluator is not a full SHACL implementation.
